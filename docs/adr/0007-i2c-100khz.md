# 0007 — I²C bus at 100 kHz

Date: 2026-07-05 · Status: **Accepted**

## Context
At 400 kHz the RV-3028 intermittently failed to ACK. The hardware review
(finding #12) notes the board lacks local HF decoupling at the I²C devices.

## Decision
Run the bus at **100 kHz** (standard mode). All devices (RTC 0x52, accel
0x18, EEPROM 0x50, amp 0x58) are registers-only, low-rate peripherals.

## Consequences
- Rock-solid bus; total traffic is tiny (poll accel at 50 Hz, RTC on sync).
- Revisit only if v2 adds HF bypass caps and a bandwidth need appears.
